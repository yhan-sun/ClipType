# ClipType v0.2.0-beta.1

This cross-platform prerelease adds:

- a native-compiled graphical Settings UI;
- user-recorded Trigger and Cancel shortcuts;
- operating-system conflict probing, live replacement, and rollback;
- the Windows x86_64 product with the P3 settings and shortcut surface;
- a macOS menu-bar app with Accessibility onboarding, clipboard/revision protection, Unicode keyboard input, Command+V, focus/cancel protections, custom global shortcuts, and Start at Login;
- Apple Silicon and Intel slices assembled as a Universal 2 app;
- Windows ZIP/EXE plus macOS ZIP/DMG distribution assets.

## macOS preview warning

The first macOS assets attached to this release are an **ad-hoc-signed, unnotarized testing preview**. Their filenames include `UNSIGNED`. They are not Developer ID signed, not Apple-notarized, and not Gatekeeper-approved. macOS may block or warn when opening them.

The maintainer explicitly requested publication before physical-Mac validation. Post-release Apple Silicon/Intel testing, Accessibility grant/revoke, Unicode and paste behavior, destination safety, global-hotkey conflict/rollback, menu-bar/settings/login-item lifecycle, privacy checks, and signed/notarized promotion are tracked in Issue #61.

Do not interpret the macOS preview as a broad compatibility claim or as a normally signed public macOS distribution.

## Windows signing

Windows assets continue to use SHA-256 manifests, Sigstore keyless signing, and GitHub artifact attestations. Authenticode is not configured, so Windows may still display an unknown-publisher or SmartScreen warning.
