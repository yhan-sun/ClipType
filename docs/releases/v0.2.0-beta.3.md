# ClipType v0.2.0-beta.3

Candidate prepared: 2026-09-05

`v0.2.0-beta.3` is prepared as a new, non-overwriting prerelease candidate. Existing beta tags,
releases, and assets remain immutable.

## Code-mode corrections

- Keeps Code mode as a distinct keyboard-only backend. It never invokes the
  Clipboard/Paste delivery path.
- Restricts pair-aware behavior to `()`, `{}`, `[]`, `""`, and `''`.
- Types brackets inside strings and comments literally instead of treating them
  as editor-generated pairs.
- Uses Right Arrow for matching generated same-line closers and line-end
  navigation for generated closers that auto-indent moved to their own line.
- Applies generated-closing-line navigation after `//` comments, avoiding extra
  blank lines and closing braces accumulating at the end of the document.
- Types Python-style `"""` and `'''` boundaries explicitly. Single backticks and
  Markdown fences remain literal.
- Preserves strict FIFO action delivery and reaches the tail of long code input
  rather than stopping at the first brace or inside a word.

## macOS target safety

For a session initially classified as a VS Code/Monaco-style render host,
Accessibility focus-node recreation is tolerated only while the frontmost
process and focused top-level window remain unchanged. A real process or window
switch, missing stable window identity, disappearance, or capture failure still
stops before the next action. Native controls keep exact focused-element
comparison.

The target adapter uses only content-free process/window/focus identity and
classification evidence. It does not read or persist window titles, selected
text, field values, document content, DOM identifier values, or class-list
values.

## Automated validation

The release candidate runs these gates from the exact source commit:

- `cargo fmt --all -- --check`
- `cargo test --workspace --locked`
- `cargo clippy --workspace --all-targets --locked -- -D warnings`
- `flutter analyze`
- `flutter test`

Regression coverage includes the documented Rust sample and `NEXT` tail,
C/C++ multi-function code, Chinese comments, nested brackets and arrays,
brackets inside strings, triple-quoted strings, generated auto-indent closing
lines, and long input.

## macOS preview warning

The macOS arm64 artifact is an **ad-hoc-signed testing preview**. It is not
Developer ID signed, not notarized, not stapled, and not a universal macOS
release. It must not be described as Gatekeeper-ready or as general macOS
support.

Hosted automation cannot grant persistent macOS Accessibility consent or carry
out a human VS Code/Monaco typing session. Those two checks are recorded as
`NOT RUN`, not inferred as passing from deterministic tests, installation, or a
launch smoke. A physical exact-release report is still required before making a
real-editor compatibility claim.

## Privacy boundary

After an explicit trigger, ClipType transiently obtains the current clipboard
text as the requested source. Code mode delivers that source only through
keyboard actions; it does not paste, replace clipboard ownership, create a
second clipboard store, log or persist plaintext, hash or transmit it, or expose
it through status channels. Destination text, selections, titles, and document
content are never read.
