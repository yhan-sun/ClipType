# ClipType v0.2.0-beta.2

This prerelease refreshes the ClipType product slice with the completed
macOS Apple Silicon Flutter front end and keeps the public release channel
on Windows x86_64.

## Highlights

- Flutter is now the sole macOS front end; the legacy macOS front end is no
  longer part of the product path.
- The macOS settings surface supports English and Simplified Chinese,
  including the language switch in the menu-bar app.
- Settings changes are validated and saved automatically, with visible save
  state and retry feedback instead of a required Apply action.
- Keyboard and Code modes remain separate from clipboard delivery, with
  code-aware paired-key handling and leading-indentation protection.
- The macOS shell keeps Accessibility onboarding, permission status, shortcut
  handling, focus protection, cancellation, and the Rust core boundary
  explicit and fail-safe.

## Public release channel

The downloadable public assets for this prerelease are Windows x86_64 builds
created by the pinned GitHub Actions release workflow. The workflow reruns the
locked workspace checks, tests, Clippy, release build, privacy scan, checksum,
Sigstore signing, and GitHub artifact attestation steps before publication.

Windows remains a beta: Authenticode publisher signing is not configured, so
SmartScreen or reputation warnings may appear. Compatibility claims remain
limited to the evidence documented in `docs/COMPATIBILITY.md`.

## macOS status

The macOS Flutter application in this source revision is an Apple Silicon
arm64 local candidate for physical validation. It is ad-hoc signed, not
Developer ID signed or notarized, and is not published as a general macOS
download. macOS requires user-granted Accessibility permission for
cross-application input, and no Universal 2, Intel, Rosetta, or Gatekeeper
compatibility claim is made.

The local candidate's settings UI and native-neutral checks were verified on
Apple Silicon. Physical Accessibility, target-application, hot-key conflict,
login-item, and distribution-signing evidence remain separate from the
Windows public beta gate.
