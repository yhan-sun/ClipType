# Contract freezes

This directory records reviewed phase contract baselines. A contract-freeze document explains the public semantic boundary and the commit from which parallel implementation work must branch. Rust source and accepted ADRs remain authoritative when a discrepancy is discovered; correct the document and contract together rather than creating adapter-local variants.

- [`P1_CONTRACT_FREEZE.md`](P1_CONTRACT_FREEZE.md) — native-neutral P1 clipboard, target, keyboard, command, bound, and outcome contracts.
