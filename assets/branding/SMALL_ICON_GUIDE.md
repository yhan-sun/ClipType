# Small-icon guide

The notification-area icon is intentionally simplified for tiny Windows surfaces:

- circular blue field;
- white clipboard silhouette;
- three document lines;
- one insertion caret;
- no flowing ribbons, pointer arrow, keycap, fine shadows, or text labels.

The generated ICO contains 16, 20, 24, 32, 48, 64, 128, and 256-pixel frames. The 16–32 pixel frames are the authoritative tray appearance; larger frames support high-DPI scaling and diagnostics.
