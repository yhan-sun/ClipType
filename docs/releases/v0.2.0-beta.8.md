# ClipType v0.2.0-beta.8

`v0.2.0-beta.8` is a regression-gate and controlled-input reliability prerelease. It keeps the beta.7 Flutter UI/UX and production input behavior while strengthening Code-mode verification and repairing the Windows controlled-host message wait used by compatibility tests.

## Code-mode regression gates

- Code remains keyboard-only and cannot fall back to Clipboard/Paste when cursor-navigation capability is unavailable.
- Heap-style multi-function fixtures are exercised repeatedly through the final source tail, including generated closing lines and LF/CRLF equivalence.
- The production mock-Quartz native contract runs under ASan/UBSan, with fail-closed mutations for unsafe modifier observations and missing prerequisites.
- macOS P4 also executes the production Swift/C bridge contracts and the complete Rust workspace quality gate from the exact candidate source.
- Gate evidence records exact source commit/tree identity so stale earlier runs are not treated as current verification.

## Windows controlled-input reliability

During beta.7 integration revalidation, the Windows Server 2022 compatibility job exposed a controlled clipboard-path mismatch: the fixture expected 73 UTF-16 units and the target observed zero. The controlled Win32 EDIT target is owned by the waiting thread; the harness previously blocked that same thread while waiting for coordinator completion, starving its message queue.

The harness now pumps the controlled target message queue before nonblocking idle observations under the existing timeout. Exact target text, expected backend, terminal outcome, clipboard content/revision preservation, and target-text deadline remain required. It does not refocus, replay input, retrigger, inject `WM_PASTE`, increase the timeout, or weaken the assertions.

Windows compatibility now requires three independent P2 processes on both Windows Server 2022 and Windows Server 2025. Every process must pass exactly one Keyboard, Clipboard, Auto-short, and Auto-long case; any missing, duplicate, or failed case fails the job immediately. These repetitions are verification runs, not retry-until-success behavior.

## Product identity

The macOS Flutter application version is `0.2.0-beta.8+7`. Flutter remains the sole macOS frontend. This release does not change production policy, settings schema, native FFI layout, clipboard privacy boundaries, target-safety rules, modifier handling, cancellation semantics, or telemetry/network behavior.

## Windows x86_64 public beta

The public-release workflow rebuilds the exact `main` commit, reruns workspace checks/tests/Clippy, builds the optimized executable, assembles the package and dependency inventory, verifies the distributable privacy boundary, creates SHA-256 manifests, signs primary assets with keyless Sigstore, generates GitHub artifact attestations, and publishes the prerelease only if the tag and release do not already exist.

Authenticode trusted-publisher signing is still not configured, so Windows reputation or SmartScreen warnings may appear.

## macOS Apple Silicon testing preview

The macOS artifact remains an **Apple Silicon arm64 testing preview**. CI builds, ad-hoc signs, installs and launch-smokes `/Applications/ClipType.app`, then packages and verifies ZIP/DMG assets before attaching them to the prerelease.

It is not Developer ID signed, notarized, stapled, Universal 2, Intel/Rosetta, or a broad macOS compatibility claim. Hosted CI does not substitute for persistent user-granted Accessibility consent or a physical VS Code/Monaco input session. Exact-package physical Accessibility grant/revoke, held-modifier, focus-change, cancellation, and real-editor acceptance remain outside hosted automation.

## Privacy and rollback

No clipboard history, telemetry, network transport, target plaintext logging, window-title logging, or automatic permission bypass is added. Failure diagnostics use fixed case/category labels and Boolean state only.

Published beta.7 assets remain immutable. If beta.8 needs remediation, publish a newer beta rather than replacing or moving the beta.8 tag/assets.
