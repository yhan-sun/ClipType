# ClipType v0.2.0-beta.4

`v0.2.0-beta.4` is a new maintenance prerelease built from the exact merged
`main` commit. Existing beta tags, releases, and assets remain immutable.

## Included behavior

This release carries the current Flutter macOS front end and the Rust runtime
with the hardened Code-mode editor-input behavior:

- Code mode remains a distinct keyboard-only backend and never uses the
  Clipboard/Paste delivery path.
- Pair-aware behavior is limited to `()`, `{}`, `[]`, `""`, and `''`.
- Generated same-line closers are skipped with Right Arrow; line-leading
  generated closers are navigated without adding blank lines or moving every
  `}` to the end of the document.
- Brackets inside strings and comments remain literal, while `"""` and `'''`
  boundaries are typed explicitly rather than treated as ordinary quote pairs.
- FIFO action delivery and macOS render-host target evidence prevent normal
  editor Accessibility-node rebuilds from causing a false stop. A real process
  or window change still stops safely.
- Flutter settings remain the sole macOS front end, with automatic settings
  persistence and Chinese UI support.

## Validation

The exact release source is required to pass:

- `cargo fmt --all -- --check`
- `cargo test --workspace --locked`
- `cargo clippy --workspace --all-targets --locked -- -D warnings`
- `flutter analyze`
- `flutter test`
- Windows x86_64 compatibility, package, controlled-input, host-smoke, and
  release gates
- macOS Apple Silicon Flutter build, arm64 bundle verification, ad-hoc signing,
  `/Applications/ClipType.app` launch smoke, ZIP/DMG packaging, and checksums

## Platform boundary

| Platform | Status | Scope |
|---|---|---|
| Windows x86_64 | Primary prerelease channel | Validated by the Windows release workflow; existing compatibility limitations apply. |
| macOS Apple Silicon | **Testing preview only** | Flutter `.app`, ZIP, and DMG; ad-hoc signed and explicitly requires Accessibility consent for cross-application input. |
| macOS Intel / Universal 2 | Not supported by this preview | No x86_64, Rosetta, or Universal 2 claim. |

The macOS preview is not Developer ID signed, notarized, stapled, Gatekeeper
ready, or a general macOS release. Hosted automation cannot grant persistent
Accessibility consent or prove a human VS Code/Monaco input session; those
checks remain `NOT RUN` until an exact-release physical report exists.

## Privacy boundary

ClipType does not log or persist clipboard plaintext, injected text, focused
field values, selected text, window titles, document contents, or DOM attribute
values. Code mode delivers through keyboard actions only.

## Rollback

Do not move or overwrite an existing tag or release. If a problem is found,
leave `v0.2.0-beta.3` available and publish a subsequent beta with the fix.
